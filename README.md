# أَثَر | ذاكرة الحضارة العربية

موقع تعريفي عربي متجاوب عن بعض المواقع الأثرية في المنطقة العربية.

## المميزات

- اختيار واحد من ستة خطوط عربية أو التنقل بينها بزر.
- تكبير وتصغير حجم الخط.
- الاحتفاظ بإعدادات الخط محليًا باستخدام `localStorage`.
- تصفية المواقع حسب المنطقة.
- تصميم متجاوب مع الشاشات المختلفة.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو استخدم Live Server في VS Code. لا يحتاج المشروع إلى تثبيت حزم. يحتاج اتصالًا بالإنترنت لتحميل خطوط Google Fonts.

## النشر باستخدام GitHub Pages

1. أنشئ مستودع GitHub جديدًا، وارفع ملفات `index.html` و`style.css` و`script.js` و`README.md` إلى جذر المستودع.
2. افتح **Settings → Pages** في المستودع.
3. تحت **Build and deployment** اختر **Deploy from a branch** ثم **main** و **/(root)** واضغط **Save**.
4. بعد نجاح النشر يظهر رابط الموقع في قسم Pages.

> لا يحتوي هذا الإصدار على صور خارجية؛ البطاقات تستخدم رموزًا وأشكالًا زخرفية.
